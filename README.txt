BHARADWAJ BADARU — PORTFOLIO

FILES
- index.html       Main portfolio page
- style.css        Dark theme, responsive layout and animations
- java.js          Navigation, scroll effects, pointer glow and contact form
- assets/bharadwaj.jpg  Your supplied portrait

HOW TO RUN
1. Extract the ZIP folder.
2. Keep index.html, style.css, java.js and the assets folder together.
3. Open index.html in Chrome, Edge or Firefox.
4. For editing, open the folder in VS Code.

CUSTOMISE
- Update text and project descriptions in index.html.
- Change colours and layout in style.css.
- Add your own project links where the current GitHub links are used.

CONTACT FORM
The form opens the visitor's default email app and prepares a message to
bharatbandaru4@gmail.com. A live website form that sends without an email app
will need a backend or a form service.
